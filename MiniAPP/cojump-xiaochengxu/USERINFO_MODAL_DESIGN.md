# 个人信息修改弹窗设计方案

## 📋 设计概述

参考微信最新的授权弹窗设计（2024年标准），为COJUMP智能康复训练系统设计一个现代化、用户友好的个人信息修改弹窗。

#### 交互流程
1. **点击"更新个人信息"按钮**
   - 弹窗从底部滑入（300ms动画）
   - 遮罩层淡入，背景模糊效果

2. **选择头像**
   - 点击头像区域
   - 调用 `wx.chooseMedia()` 或 `button open-type="chooseAvatar"`
   - 预览新头像（本地临时显示）

3. **修改昵称**
   - 点击昵称区域
   - 输入框激活，允许编辑
   - 实时显示字符数限制（如：8/12）

4. **确认修改**
   - 验证输入（昵称不为空）
   - 显示加载状态
   - 上传头像到云存储
   - 调用云函数更新数据
   - 成功提示，关闭弹窗

5. **取消修改**
   - 弹窗滑出
   - 不保存任何修改

## 🖼️ 头像存储方案对比

### 方案A：云存储（推荐）⭐

#### 优点
- ✅ 多端同步（小程序、Web、App等）
- ✅ 永久保存，不会丢失
- ✅ CDN加速，加载快速
- ✅ 便于管理和备份
- ✅ 支持图片处理（压缩、裁剪）

#### 缺点
- ❌ 需要云存储配置
- ❌ 占用云存储空间（但成本极低）

#### 实现流程
```
1. 用户选择头像
   ↓
2. 上传到云存储（wx.cloud.uploadFile）
   ↓
3. 获取云存储URL（fileID）
   ↓
4. 调用云函数保存URL到数据库
   ↓
5. 更新本地缓存
```

#### 代码示例
```javascript
// 1. 选择头像
wx.chooseMedia({
  count: 1,
  mediaType: ['image'],
  sourceType: ['album', 'camera'],
  success: (res) => {
    const tempFilePath = res.tempFiles[0].tempFilePath
    
    // 2. 上传到云存储
    wx.cloud.uploadFile({
      cloudPath: `avatars/${app.globalData.openId}_${Date.now()}.jpg`,
      filePath: tempFilePath,
      success: (uploadRes) => {
        const avatarUrl = uploadRes.fileID
        
        // 3. 更新数据库
        this.updateAvatarToCloud(avatarUrl)
      }
    })
  }
})
```

### 方案B：本地存储

#### 优点
- ✅ 实现简单
- ✅ 无需云配置
- ✅ 响应速度快

#### 缺点
- ❌ 无法多端同步

- ❌ 无法在其他设备访问

#### 适用场景
- 仅用于临时预览
- 开发阶段测试
- 不需要多端同步的场景

```
  ↓
```

```
点击"取消"或遮罩层

弹窗滑出（300ms）
```

## 🔐 头像上传最佳实践

### 图片处理流程
```
1. 选择图片
   ↓
2. 压缩图片（建议尺寸：500×500，质量：80%）
   ↓
3. 生成缩略图（可选，100×100用于列表显示）
   ↓
4. 上传到云存储
   ↓
5. 获取云存储URL
   ↓
6. 保存到数据库
```

### 云存储路径设计
```
/avatars/
  ├─ {openId}_1698234567890.jpg  (原图)
  └─ thumb_{openId}_1698234567890.jpg  (缩略图，可选)
```

### 图片压缩代码示例
```javascript
wx.compressImage({
  src: tempFilePath,
  quality: 80,
  success: (res) => {
    // 使用压缩后的图片
    uploadToCloud(res.tempFilePath)

})
```

## 💡 设计建议

### 用户体验优化
1. **即时预览**：选择头像后立即显示预览

1. **图片校验**：检查图片格式和大小
2. **敏感词过滤**：昵称敏感词检测
3. **频率限制**：限制修改频率（如：1小时1次）
4. **权限验证**：验证用户登录状态
