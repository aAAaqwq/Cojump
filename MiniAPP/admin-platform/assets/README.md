# 图标资源说明

本文件夹用于存放登录页面所需的图标资源。

## 所需图标列表

### 1. logo.png
- 尺寸：建议 200x200px 或更大（正方形）
- 格式：PNG，支持透明背景
- 用途：应用Logo，显示在登录页面顶部
- 说明：如果暂时没有Logo，可以使用纯色或渐变色的占位图

### 2. icon-user.png
- 尺寸：建议 64x64px
- 格式：PNG，支持透明背景
- 用途：账号输入框图标
- 建议：使用简洁的用户头像图标

### 3. icon-lock.png
- 尺寸：建议 64x64px
- 格式：PNG，支持透明背景
- 用途：密码输入框图标
- 建议：使用锁形状图标

### 4. icon-eye-open.png
- 尺寸：建议 64x64px
- 格式：PNG，支持透明背景
- 用途：显示密码图标
- 建议：使用睁开的眼睛图标

### 5. icon-eye-close.png
- 尺寸：建议 64x64px
- 格式：PNG，支持透明背景
- 用途：隐藏密码图标
- 建议：使用闭合的眼睛图标

## 图标资源获取建议

1. **自行设计**：使用 Figma、Sketch 等设计工具创建
2. **图标库**：
   - [iconfont](https://www.iconfont.cn/) - 阿里巴巴图标库
   - [iconify](https://iconify.design/) - 开源图标库
   - [feathericons](https://feathericons.com/) - 简洁线条图标
   - [heroicons](https://heroicons.com/) - Tailwind官方图标

3. **临时替代方案**：
   - 使用文字图标（已在代码中实现）
   - 使用emoji表情符号

## 当前状态

目前登录页面使用了Unicode字符作为临时图标：
- 👤 用户图标
- 🔒 锁图标  
- 👁 眼睛图标

您可以在准备好图标资源后，将图标文件放入此文件夹，即可自动替换显示。

## 注意事项

1. 所有图标建议使用相同的风格和色调
2. 建议使用矢量图标或高清PNG，确保在不同设备上清晰显示
3. 图标文件命名必须与上述列表一致
4. 建议图标颜色为深灰色（#666666）或与主题色相关的颜色
