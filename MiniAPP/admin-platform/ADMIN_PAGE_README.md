# 管理员用户管理页面使用说明

## 📋 页面概述

这是专为管理员设计的用户管理中心，提供完整的用户查询、管理和删除功能。界面采用现代化设计，支持搜索、筛选、分页等实用功能。

## ✨ 主要功能特性

### 🎨 界面设计特点
- **渐变色彩方案**：紫色系渐变背景，营造专业感
- **卡片式布局**：清晰的信息层次结构
- **响应式设计**：适配不同屏幕尺寸
- **动画效果**：流畅的交互动画和过渡效果

### 🔍 搜索和筛选功能
- **实时搜索**：支持按OpenID或用户名搜索
- **快速筛选**：全部用户、活跃用户、非活跃用户
- **搜索历史**：保留搜索关键词，便于下次使用

### 📊 用户信息展示
- **表格布局**：清晰的用户信息表单
- **用户信息列**：
  - 用户名/OpenID显示 --string
  - EMG阈值数据       --number
  - EMG阈值记录时间   --string
- **操作按钮**：编辑和删除功能

### 🎯 交互体验
- **悬停效果**：表格行悬停高亮
- **选中状态**：支持行选择高亮
- **确认对话框**：删除操作的安全确认
- **加载状态**：清晰的加载反馈

## 🚀 使用指南

### 基本操作

#### 1. 查看用户信息
- 页面自动加载用户列表
- 默认按照同一用户名，时间前后排序
- 支持分页浏览（每页10条记录）
- 显示总用户数和在线用户统计

#### 2. 搜索用户
1. 在搜索框输入关键词（OpenID或用户名）
2. 点击搜索按钮或按回车键
3. 系统会实时过滤显示匹配的用户

#### 3. 筛选用户
- 点击筛选按钮切换用户类型：
  - **全部用户**：显示所有用户
  - **活跃用户**：显示活跃状态用户
  - **非活跃用户**：显示非活跃状态用户

#### 4. 编辑用户（开发中）
- 点击用户信息行的"编辑"按钮
- 系统会弹出编辑提示（功能待扩展）

#### 5. 删除用户
1. 点击用户信息行的"删除"按钮
2. 系统显示确认对话框
3. 点击"确定删除"完成操作
4. 显示删除成功提示

### 分页操作

#### 页面导航
- **上一页/下一页**：翻页浏览
- **页码跳转**：点击具体页码快速跳转
- **自动分页**：超过10条记录自动分页显示

## ❓ 常见问题

### Q: 如何修改显示的用户数量？
A: 在 `home.js` 的 `data` 中修改 `pageSize` 值

### Q: 如何添加新的筛选条件？
A: 在 `home.js` 的筛选逻辑中添加新的筛选条件

### Q: 如何修改表格列？
A: 在 `home.wxml` 中修改表格结构，添加或删除列
