# 管理员后台小程序

这是一个精美的微信小程序管理员后台登录系统，采用现代化设计风格和流畅的交互体验。

## ✨ 特性

### 🔐 登录系统
- 🎨 **现代化设计**：采用渐变色背景和卡片式布局
- 🔐 **完整登录功能**：包含账号密码验证、记住密码、显示/隐藏密码等功能
- 💫 **流畅动画**：页面加载动画、按钮点击反馈、加载状态提示
- 📱 **响应式布局**：适配各种屏幕尺寸
- 🎯 **用户体验优化**：输入框聚焦效果、表单验证、错误提示

### 👥 用户管理中心
- 📊 **数据概览**：实时显示总用户数、在线用户统计
- 🔍 **智能搜索**：支持按OpenID或用户名实时搜索
- 🎛️ **灵活筛选**：全部用户、活跃用户、非活跃用户分类查看
- 📋 **表格展示**：清晰的用户信息表格，包含EMG阈值状态
- ⚡ **操作便捷**：支持批量选择、快速编辑、删除确认
- 📄 **分页浏览**：支持大数据量分页显示
- 🎨 **美观界面**：现代化卡片设计，丰富的交互动效

## 🚀 快速开始

### 1. 环境要求

- 微信开发者工具
- Node.js（可选，用于代码规范检查）

### 2. 安装依赖

```bash
npm install
# 或
yarn install
```

### 3. 配置云开发

在 `app.js` 中修改云开发环境ID：

```javascript
wx.cloud.init({
  env: 'your-cloud-env-id', // 替换为您的云开发环境ID
});
```

### 4. 运行项目

1. 使用微信开发者工具打开项目
2. 选择"小程序"项目类型
3. 填写 AppID（或使用测试号）
4. 点击"编译"运行项目

## 🎯 登录页面功能说明

### 表单验证
- 账号长度不少于3位
- 密码长度不少于6位
- 实时输入验证和错误提示

### 交互功能
- ✅ 记住密码功能（使用本地存储）
- 👁 密码显示/隐藏切换
- 🔄 登录加载状态提示
- 💡 输入框聚焦高亮效果

### 登录逻辑
当前使用模拟登录，实际项目中需要：

1. 在 `pages/login/login.js` 的 `onLogin` 方法中修改登录逻辑
2. 替换为实际的后端API调用或云函数调用

示例代码（已在login.js中注释）：
```javascript
const result = await wx.cloud.callFunction({
  name: 'adminLogin',
  data: {
    username,
    password
  }
});
```

## 🎨 自定义主题色

### 修改渐变色
在 `pages/login/login.wxss` 中修改：

```css
/* 主渐变色 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 可替换为其他渐变色方案，例如： */
/* 蓝绿渐变 */
background: linear-gradient(135deg, #667eea 0%, #00d4ff 100%);

/* 粉紫渐变 */
background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);

/* 橙红渐变 */
background: linear-gradient(135deg, #fa709a 0%, #fee140 100%);
```

### 修改Logo和图标
1. 参考 `assets/README.md` 中的说明
2. 准备相应尺寸的图标文件
3. 放入 `assets` 文件夹
4. 修改 `pages/login/login.wxml` 中的图标引用

## 🔒 安全建议

1. **密码存储**：
   - 生产环境不建议在本地存储明文密码
   - 可使用加密存储或仅存储用户名

2. **登录验证**：
   - 实现真实的后端验证逻辑
   - 添加登录失败次数限制
   - 实现Token机制管理登录状态

3. **数据传输**：
   - 使用HTTPS协议
   - 对敏感数据进行加密传输

## 📋 使用流程

### 登录流程
1. **启动应用** → 显示精美登录页面
2. **输入凭证** → 账号密码验证（支持显示/隐藏密码）
3. **登录成功** → 跳转到用户管理中心

### 管理操作流程
1. **查看概览** → 实时统计数据展示
2. **搜索用户** → 输入关键词快速定位
3. **筛选分类** → 按状态分类浏览用户
4. **管理用户** → 编辑或删除用户（安全确认）
5. **分页浏览** → 大数据量分页显示
